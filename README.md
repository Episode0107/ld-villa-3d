# L&D Villa - 3D Viewer

Interactive 3D viewer for the L&D Villa architectural model (+EMA site).

- index.html - three.js viewer (orbit / zoom / pan), loads ld-villa.glb
- ld-villa.glb - web-optimized model converted from 260112_L&D Villa.3dm (Rhino 8)
- converter.html - in-browser Rhino-to-GLB converter (runs locally, nothing uploaded)
